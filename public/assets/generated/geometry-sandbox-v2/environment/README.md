# Geometry-Sandbox Environment Hero Assets

## `iron-mine-hero-v1.png`

Neue Erzminen-Landmark für die orthografische 2.5D-Sandbox. Sie ergänzt die
bereits vorhandene `fungus-grotto.png`, weil im bisherigen Bestand keine
vergleichbar ausgearbeitete Erzminen-Komposition vorhanden war.

Art-Direction-Referenzen:

- `docs/mockups/HOLLOW_COVENANT_STYLE_B_DUNGEON_ADMIN.png`
- `docs/mockups/HOLLOW_COVENANT_STYLE_B_PRODUCTION_FRAME.png`

Erzeugt mit dem eingebauten ImageGen-Werkzeug und anschließend über einen
Magenta-Chroma-Key in ein Alpha-PNG umgewandelt.

Kurzfassung des finalen Prompts:

> Premium hand-painted orthographic fantasy iron-mine chamber matching the
> Style-B mockups: irregular blue-black cave-rock island, warm exposed iron
> veins, timber braces, lanterns, ore cart, rails, tools, rubble and restrained
> teal cave growth. Readable at mobile scale, isolated on a flat magenta
> chroma-key background, without characters, UI, text or repeated icon rows.
