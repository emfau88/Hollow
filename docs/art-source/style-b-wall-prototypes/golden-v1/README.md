# Golden-v1 ImageGen source ledger

These PNGs are high-resolution chroma masters. Runtime atlases are generated by
`scripts/asset_tools/pack_style_b_golden_v1.py`; do not load the masters in the
game.

## Selected sources

- `built-sheet-master-v2.png` — selected 4x4 Covenant masonry sheet. V2 removes
  brass endpoint posts from straight frames so gold appears at structural nodes
  rather than every 32 px tile.
- `corridor-sheet-master.png` — selected 4x4 low blue-gray dug-passage family.
- `threshold-built-master.png` — 2x2 N/E/S/W formal threshold source.
- `threshold-natural-master.png` — 2x2 N/E/S/W corridor/natural threshold source.
- `built-concave-se-master.png` — single-frame replacement for built frame 10.
- `corridor-concave-sw-master.png` — single-frame replacement for corridor frame 11.
- `built-sheet-master.png` — retained first-generation Built source for lineage;
  superseded by V2.

## Prompt anchors

Every generation used the production mockup as projection/style reference and
the existing V4 or Golden sheet as material/topology reference. The shared
prompt contract was:

> Orthographic, screen-aligned top-down 2.5D; never isometric. Fixed upper-left
> key light and down-right contact shadow. Exact V7 row-major frames N/E/S/W,
> convex NW/NE/SE/SW, concave NW/NE/SE/SW, two connected diagonals, two empty
> reserves. Logical pivot centered per source cell. Flat opaque #FF00FF
> background and gutters; no grid, labels, text, props, floor, or scene.

Built-specific direction:

> Pale cream-gray capstone, deep plum facade, restrained Covenant brass only on
> true structural nodes. Chunky hand-painted silhouettes and substantial wall
> depth. Straight V2 modules use one broad stone run, no brass endpoint posts.

Corridor-specific direction:

> Low dug-passage rock lips in cool blue-gray slate and deep navy, sparse dark
> iron, restrained cyan mineral glints, no Covenant gold, and enough open floor
> for a one-tile passage.

Threshold-specific direction:

> Four separately lit N/E/S/W open-passage sills, compact and low, never a
> blocking wall or door leaf. Built uses pale stone/brass; natural uses slate,
> iron, and cyan marker studs.

The two correction prompts explicitly required connected center arms toward
south+east (built frame 10) and south+west (corridor frame 11). All masters were
then Chroma-keyed, normalized into 96 px directional envelopes, and validated
by the strict asset contract.
